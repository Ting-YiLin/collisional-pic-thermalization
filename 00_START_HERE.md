# Start here

1. Read `README.md`.
2. For the public portfolio validation, run `validate_thesis.bat` (Windows) or `./validate_thesis.sh` (Linux/macOS).
3. A valid representative run must print `THESIS_VALIDATION_PASS`.
4. Thesis validation uses `collision_alpha=3`; do not silently replace it with the Appendix example's alternate value.
5. See `validation/VALIDATION.md` for the exact claim boundary.
