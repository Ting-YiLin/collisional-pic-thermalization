# v1.0.0 — Recovered & Validated Thesis Research Code

This release publishes the recovered 1D electrostatic Particle-in-Cell simulation code Ting-Yi Lin developed for his master's research and a modern validation wrapper.

Included:
- recovered historical C++ source;
- thesis-validation parameter preset with `collision_alpha=3`;
- one-click representative validation (`validate_thesis.bat` / `validate_thesis.sh`);
- frozen validation report and representative evidence;
- provenance and paper-to-code documentation;
- citation metadata and MIT license.

Validation status: **validated against the thesis results**. Representative reruns reproduce the main reported trends and mechanisms. This release does not claim exact point-by-point identity with every historical random realization or a full replication of the later 2014 paper.
