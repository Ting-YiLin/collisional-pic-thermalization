# Publish checklist

## GitHub

1. Create a public repository named `collisional-pic-thermalization`.
2. Upload the **contents** of this package, not the outer folder itself.
3. Repository description:
   `Reproducible archive of a 1D electrostatic PIC simulation for numerical thermalization with Monte-Carlo collisions.`
4. Website field: `https://doi.org/10.1063/1.4904307`
5. Suggested topics: `plasma-physics`, `particle-in-cell`, `computational-physics`, `monte-carlo`, `numerical-simulation`, `cplusplus`, `reproducible-research`.
6. Set `assets/social_preview.png` as the repository social preview.
7. Before granting reuse rights, choose a license. If the goal is maximum research reuse, MIT is a simple code-license option; if the goal is display-only, leave the repository without an open-source license until a decision is made.
8. Do **not** upload the publisher's journal PDF. Link the DOI instead.

## LinkedIn

1. Add the GitHub repository to **Featured**.
2. Use the title and short description in `docs/LINKEDIN_COPY.md`.
3. Optionally publish the longer post in the same file.
4. Link both the GitHub repository and the paper DOI.

## Completion criterion

This project is complete when the GitHub repository is public, its social preview is set, the DOI/thesis links work, and the repository is attached to LinkedIn Featured. No further code generalization is required for the portfolio objective.
